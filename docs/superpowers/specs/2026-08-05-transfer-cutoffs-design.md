# 지역별 전보 커트라인 추이 — 설계

## 배경

경기도교육청은 매년 3월 인사 시즌 전, "지역별 청간전보 커트라인" 자료를 발표한다. 지역(= `office`, 25개 인사구역)별로 그 해 전입 가능했던 최소 조건(전보년수.점수 + 급지, 또는 "신규"/"특만기(N희망)"/전원수용)을 담고 있다.

현재 앱은 `data/gyeonggi-zones-2027.json` 기반으로 학교별 갑/을/병 급지만 보여준다. 급지는 "그 지역이 몇 급지인가"를 말해주지만, "실제로 그 지역에 전입하려면 작년 커트라인이 얼마나 높았는가"는 알려주지 않는다. 사용자는 2022, 2023, 2025, 2026년도 커트라인 PDF 4개를 확보했고, 이를 지역 선택 UI 옆에 참고 정보로 노출하고자 한다.

정기전보(2022, 2023)와 청간전보(2025, 2026) 자료는 성격이 다른 전형이지만, 사용자 지시에 따라 **구분하지 않고 "청간전보"라는 명칭 아래 연도순 단일 표**로 합쳐서 다룬다.

## 데이터 소스 원문

| 연도 | 파일 | 비고 |
|---|---|---|
| 2022 | `2022.3.1.자 초등교사 정기전보 지역별 커트라인.pdf` | |
| 2023 | `2023.3.1.자 초등교사 정기전보 지역별 커트라인.pdf` | |
| 2025 | `2025.3.1.자 초등교사 청간전보 지역별 커트라인.pdf` | |
| 2026 | `2026.3.1.자 초등교사 청간전보 지역별 커트라인.pdf` | |

(2024년 자료는 확보하지 못함 — 데이터 없이 빈 값으로 취급)

## 데이터 모델

`data/transfer-cutoffs.json` (신규, 수동 작성/유지):

```json
{
  "years": [2022, 2023, 2025, 2026],
  "regions": {
    "<office>": [
      { "year": 2022, "status": "신규" },
      { "year": 2023, "status": "특만기", "rank": 2 },
      { "year": 2025, "status": "전원수용" },
      { "year": 2026, "cutoff": "4.03", "zone": "우" }
    ]
  }
}
```

- `regions`의 키는 `office` 값(예: `수원`, `광주하남`)과 정확히 일치해야 한다 — `data/schools.json`의 25개 `office`와 1:1 매핑 확인 완료.
- 연도별 엔트리는 다음 중 하나의 형태:
  - `status: "신규"` — 원문 "신규" (전원 수용, 경력 무관)
  - `status: "전원수용"` — 원문 `-` (해당 연도엔 커트라인 없이 전원 전입)
  - `status: "특만기", rank: N` — 원문 "특만기(N희망)"
  - `cutoff: "X.XX", zone: "갑"|"을"|"병"|"수"|"우"|"미"` — 원문 "X.XX(급지)" 형태의 실제 커트라인. 급지 문자는 원문 그대로 보존(수/우/미 등 인사자료 특유 표기이며 학교 급지 갑/을/병과는 다른 축이므로 별도 색상 매핑 사용).
- 4개 PDF에서 이미 텍스트를 추출했으므로 값 채우는 작업은 구현 단계에서 바로 진행.

## 백엔드

- `src/lib/cutoffs.ts` (신규): `src/lib/schools.ts`와 동일한 패턴으로 JSON 로더 작성. `getCutoffsByOffice(office: string)` 함수 제공.
- `src/app/api/cutoffs/route.ts` (신규): `GET /api/cutoffs?office=수원` — 해당 지역의 연도별 배열 반환. `office` 쿼리 없으면 전체 반환.
- `src/types/school.ts`에 `CutoffEntry`, `RegionCutoffs` 타입 추가.

## 프런트엔드

- `src/components/CutoffPanel.tsx` (신규):
  - props: `office: string`
  - `/api/cutoffs?office=...` fetch, 연도를 열로 하는 작은 표 렌더링
  - 셀 표시 규칙:
    - `cutoff` 있으면 `"4.03(우)"` 형태로 표시, 텍스트 색은 급지 문자에 따라 강조(기존 `ZONE_COLOR` 팔레트와 별개의 소규모 매핑 사용 — 급지 축이 다르므로 재사용하지 않음)
    - `status: "신규"` / `"전원수용"` → 회색 텍스트로 "신규" / "전원 수용"
    - `status: "특만기"` → "특만기(N희망)"
  - 데이터 없는 연도(2024 등, 또는 fetch 실패)는 빈 칸("-")
- `src/components/AppShell.tsx`: `city`(=office)가 선택된 상태에서 `Filters` 컴포넌트 바로 아래, 학교 목록 위에 `<CutoffPanel office={city} />` 삽입. 기존 `fetch("/api/schools?...")`와 같은 `useEffect` 패턴으로 city 변경 시 재조회.

## 범위 밖

- PDF 자동 파싱 스크립트 — 데이터가 작고(25지역×4년) 매년 3월에만 갱신되므로, 신규 연도는 이 JSON 파일에 수동으로 항목을 추가하는 것으로 충분하다고 판단.
- 학교 카드/지도 마커에 커트라인 정보 노출 — 1차는 지역 선택 시 사이드바 패널로만 제공.
- 정기전보/청간전보 구분 표시 — 사용자 지시에 따라 통합.

## 테스트/검증

- `/api/cutoffs?office=수원` 등 몇 개 지역에 대해 응답 확인
- `CutoffPanel`이 도시 변경 시 올바르게 갱신되는지, 데이터 없는 지역(있을 경우) 처리 확인
- 브라우저에서 시·군 선택 → 패널 표시 → 값이 원문 PDF와 일치하는지 육안 대조
